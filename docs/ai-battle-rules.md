# AI 대전 규칙

AI 대전 준비 화면에서 싱글/더블을 선택한 후 기존 128강 토너먼트 또는 8인 리그에 참가한다. 팀 1~5에서 고른 6마리를 등록하고 매 경기 출전 포켓몬을 직접 선출한다.

| 형식 | 등록 | 출전 | 선봉 |
| --- | --- | --- | --- |
| 싱글 | 6마리 | 3마리 | 첫 번째 선택 |
| 더블 | 6마리 | 4마리 | 첫 번째와 두 번째 선택 |

- 형식별 출전 수는 레이팅의 `RANKED_FORMATS`를 기준으로 사용한다. 레벨은 50이다.
- 대회를 시작할 때 `competition.battleFormat`을 저장하며 다음 라운드에서도 같은 형식을 유지한다.
- 매 라운드 선출은 빈 상태로 시작한다. 정원을 채운 뒤에는 기존 선택을 취소해야 다른 포켓몬을 고를 수 있다.
- 모든 경기는 맑음·일반 필드에서 시작한다. 날씨, 필드, 형식, 출전 수, 기믹 금지를 임의로 추첨하지 않는다.
- 준비한 배틀 기믹은 각각 대전당 1회 사용할 수 있다. 기존 AI 난이도 효과는 유지한다.
- 등장 특성, 기술, 다이맥스 기술에 의한 환경 변경은 정상적으로 적용된다. 임시 효과가 끝나거나 필드를 제거하면 맑음·일반 필드로 전환하며 이전 환경을 복원하지 않는다. 강한 날씨의 원천 특성이 남아 있는 동안 유지되는 규칙도 보존한다.

## 검증

- `npm run validate:ai-battle-formats`: 레이팅과의 출전 수·선봉·활성 슬롯 비교, 양 형식의 토너먼트/리그 7경기 유지, 기본 환경, 난이도 및 기존 전원 출전 선봉 순서.
- `npm run validate:ai-battle-formats-ui`: 외부/API 요청을 차단한 실제 GameApp에서 PC·모바일 선택과 경기 시작 및 다음 라운드 전환.
- `npm run validate:battle-environment`: 실제 엔진으로 다이맥스 환경의 지속/만료, 연장 도구, 필드 제거 기술, 등장 특성, 강한 날씨 교체 조건.

UI 검증의 라운드 종료 주입은 화면 전환만 검증하는 명시적 픽스처이며 실제 승리 시뮬레이션으로 간주하지 않는다. 배틀 환경 검증은 실제 기술과 턴 처리를 사용한다.
