# 기술 PP 트레이닝

트레이닝의 기술 설정에서 기술별 PP를 1회마다 1씩 늘릴 수 있다. 강화 1회 비용은 100 VP이며, 기존 트레이닝 저장 단계에서 다른 변경 비용과 함께 결제한다. 저장하지 않은 변경은 포켓몬에게 적용되지 않는다.

## 기술별 한도

기본 PP와 기본 위력을 기준으로 다음 순서로 분류한다. 강화 후 PP로 한도를 다시 계산하지 않는다.

| 조건 | 최대 강화 횟수 | 예시 |
| --- | --- | --- |
| 기본 PP가 10 이하이거나 위력이 100 이상 | 3회 | 파괴광선, 인파이트, 방어 |
| 위 조건에 해당하지 않고 기본 PP가 20 이상이며 위력이 60 이하 | 5회 | 몸통박치기, 칼춤 |
| 나머지 기술 | 4회 | 화염방사 |

변화 기술의 위력은 0으로 취급한다. 각 기술의 최종 최대 PP는 기본 PP에 강화 횟수를 더한 값이다. 예를 들어 기본 PP 5의 인파이트는 최대 PP 8까지, 기본 PP 35의 몸통박치기는 최대 PP 40까지 강화할 수 있다.

## 저장과 배틀 반영

포켓몬의 `movePpUps` 객체에 기술 ID를 키로 강화 횟수를 저장한다. 예: `{ "closecombat": 3 }`. 기존 저장 데이터는 강화 0회로 처리한다. 정규화 과정에서 현재 배우고 있는 기술만 남기고, 잘못된 값은 제거하며, 횟수는 해당 기술의 한도를 넘을 수 없게 한다.

기술의 순서를 바꿔도 강화가 유지된다. 기술을 교체하거나 지우면 해당 기술의 강화는 초기화되고, 나중에 다시 배우더라도 자동으로 복구되지 않는다. 비용은 증가한 강화 횟수에 대해서만 계산하며, 감소분으로 다른 강화 비용을 상쇄하지 않는다.

AI 배틀, 레이팅 및 배틀방에서 강화된 최대 PP로 시작한다. 일반 PP 소비, 프레셔의 추가 소비, 과사열매의 PP 회복과 PP 0일 때 발버둥 판정은 강화된 PP에 적용된다. 과사열매는 강화된 최대 PP를 초과해 회복하지 않는다. 자시안·자마젠타가 왕폼으로 변해 아이언헤드가 거수참·거수탄으로 바뀌면 해당 기술의 더 낮은 한도인 3회까지만 배틀 PP에 반영한다.

## 검증

프로젝트 루트에서 다음 명령을 실행한다.

```powershell
npm run validate:move-pp-training
npm run validate:move-pp-training-ui
npm run validate:training-moves
npm run validate:training-move-slots
npm run validate:crowned-moves
npm run build
```

`validateMovePpTraining.mjs`는 한도 3·4·5, 기존 저장 호환, 잘못된 강화값 정리, 중복 PP 증가 방지, 기술 교체와 순서 변경, VP 비용, 실제 턴의 소비와 회복, 왕폼 기술 치환, 저장 및 마이그레이션, 온라인 배틀의 양쪽 PP 보존을 검사한다. 트레이닝 화면의 클릭·저장·새로고침과 배틀 PP 표시도 별도 브라우저 검증으로 확인한다.
