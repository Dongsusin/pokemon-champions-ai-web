# 모드 선택·솔로 보스전 통합 검증

기준: 운영 main `5a1076238ce9c2d3138f8d41a3cef8e94be3f866`.
소스: 보스전 작업 브랜치 `28a5b14276c1599e36be93e53feeaed7cd1a999c`에서 필요한 변경만 이식했다.

## 변경 범위

- 다섯 모드 선택 탭과 소개·진입 화면, 저장 팀을 사용하는 솔로 보스전.
- 뮤츠·칠색조·루기아의 3라운드, 연속 전투·대화, HP 계승, 전용 편성·AI·기믹, 배경 9개와 폼 이미지.
- 공용 배틀 엔진·화면·트레이너 이미지의 보스전 진입점.
- 최신 고정 16:9 프레임, 팩토리 챌린지, 계정 저장·통신, 일반 전투 툴팁·기권 확인 구현은 보존했다.
- 서버, API, 인증·계정·지갑, 일반 트레이너 생성 데이터, 배포 설정은 변경하지 않았다. 과거 협동전 서버는 추가하지 않았다.

## 통합 중 수정

- 기존 모바일 모드 카드 CSS와 새 탭 CSS의 이름 충돌을 분리했다.
- 보스전 준비 화면의 `raid-view` 클래스가 전투 화면에 남지 않게 했다.
- 기존 UI 검증이 삽입하는 export와 충돌하던 불필요한 공용 helper export를 제거했다.
- 화학변화가스·위액으로 특성이 억제된 뮤츠가 메가진화할 때 억제 상태와 새 특성의 복원값을 보존했다. 일반 메가진화와 동일한 특성 갱신 함수를 사용하며 보스 HP는 유지한다.
- 로컬 검증도 실제 main → 고정 iframe → gameEntry 구조와 운영 CSS 순서를 사용한다. 온라인 계정·API는 격리한다.
