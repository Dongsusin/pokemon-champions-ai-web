# 업적과 보상

현재 카탈로그는 **278개 업적**으로 구성됩니다. 기존 일반 업적 35개와 AI 트레이너 238명 각각의 첫 승리 업적에 엘리트 업적 5개를 추가했습니다. 기존 273개 보상은 44,800 VP, 엘리트 보상은 700,000 VP로, 전체 업적의 보상 합계는 **744,800 VP**입니다. 업적은 계정별로 한 번씩 달성하고 보상을 받습니다.

로비의 **업적** 메뉴와 **설정 → 업적** 탭에서 조건, 진행도, 보상, 달성일을 확인할 수 있습니다. 설정의 업적 탭은 현재 배틀 화면을 유지한 채 열리고 닫힙니다. 승리 기록·배틀 도전·기믹 마스터·무대 정복·대회 업적·AI 첫 승리·도감 완성·궁극의 도전 분류와 검색을 제공합니다.

상태는 **전체 / 미달성 / 달성**, 정렬은 **추천 / 진행도 / 최근 달성 / 이름** 중 선택합니다. 추천은 미달성 업적 중 진행 비율이 높은 순서로 보여줍니다. 일반 보상은 VP 액수를 표시하고, 미달성 희귀 보상은 **`?`**로 표시합니다. 희귀 보상의 이름·이미지·VP 액수는 달성 후에만 공개하며 검색이나 정렬 순서로도 미리 드러나지 않습니다.

| 대표 조건 | 업적 보상 |
| --- | ---: |
| AI 트레이너별 최초 1회 승리 | 각 100 VP |
| 첫 승리 / 누적 10·50·100승 | 200 / 300 / 700 / 1,200 VP |
| 한 번도 기절하지 않고 승리 / 기믹 없이 승리 | 각각 200 VP |
| 기절과 기믹 사용 모두 없이 승리 | 500 VP |
| 5턴 이내 승리 / 지닌 도구 없이 출전해 승리 | 각각 300 VP |
| 3마리 이상으로 시작해 마지막 1마리만 남기고 승리 | 300 VP |
| 3마리 이상이 같은 타입 하나를 공유하는 팀으로 승리 | 400 VP |
| 메가진화·Z기술·다이맥스·테라스탈·원시회귀 사용 후 승리 | 기믹별 300 VP |
| 하드 난이도 승리 / 하드 상대 강화 +3단계 승리 | 400 / 500 VP |
| 3·5·10연승 | 300 / 600 / 1,000 VP |
| 리그 우승 / 토너먼트 우승 / 리그 7경기 전승 우승 | 1,000 / 800 / 1,500 VP |

기절 없는 승리와 기믹 없는 승리의 10회 누적, 서로 다른 AI 5·25·100명 및 전체 제패, 지역·무대 탐방 업적도 포함됩니다. 정확한 목록과 보상은 `src/data/achievementData.js`의 `ACHIEVEMENTS`가 기준입니다.

## 엘리트 업적

| 업적 | 달성 조건 |
| --- | --- |
| 불패의 리그 지휘관 | 노말·하드 난이도의 리그 7경기 전체에서 기절 없이 전승 우승 |
| 완전무결한 토너먼트 | 노말·하드 난이도로 128강부터 결승까지 7경기 전체에서 기절 없이 우승 |
| 전국도감의 완성 | 획득 가능한 전국도감 1,025종 수집 |
| 모든 빛깔의 발견 | 획득 가능한 전국도감 1,025종의 이로치 해금 |
| 챔피언의 모든 증명 | 이 업적을 제외한 나머지 277개 업적 달성 |

무기절 우승은 마지막 경기만 검사하지 않습니다. `competitionData.js`가 `achievementRun`에 각 라운드의 완료 여부, 승패, 난이도, 출전 팀 크기와 누적 기절 횟수를 보존합니다. 실제 우승한 대회의 7개 경기 기록이 모두 확인되어야 하며, 중간에 이지 난이도·기권·기절·누락된 기록이 있으면 달성할 수 없습니다. 초반 경기에서 기절한 포켓몬을 부활시켜 최종전에서 전원이 살아 있어도 해당 대회는 제외합니다.

전국도감의 목표는 현재 뽑기와 진화계열 해금으로 획득 가능한 종에서 계산합니다. 뽑기에는 최종 진화 **568종**이 등장하고, 진화계열 해금으로 **1,025종**에 도달할 수 있습니다. 이로치 역시 직접 뽑히지 않는 아기 포켓몬까지 각각 뽑도록 요구하지 않습니다. 같은 진화계열의 포켓몬에게 `shinyObtained` 기록이 있으면 그 계열에서 변경 가능한 종 전체를 이로치 해금으로 인정합니다. 일반색으로 표시하도록 바꾸어도 획득 기록은 유지됩니다. 중복 개체나 같은 종의 다른 폼으로 진행도를 늘릴 수는 없습니다.

수집 업적은 뽑기 이후뿐 아니라 게임을 시작할 때 기존 저장 컬렉션도 검사합니다. 마지막 수집·배틀 업적을 달성하면 전체 업적 달성도 같은 정산에서 처리합니다. 자신을 다시 조건에 포함하지 않으므로 순환 조건이 생기지 않습니다.

네 가지 희귀 포켓몬 보상은 **능력치·특성·기술을 강화하지 않는 전용 외형**입니다. 해금 후 트레이닝에서 무료로 변경할 수 있고, 해당 기본 포켓몬을 아직 보유하지 않았다면 한 번 지급합니다. 이미 보유한 포켓몬은 기존 육성 상태를 유지합니다. 마지막 희귀 도구는 일반 상점 구매나 AI 장비 목록에 추가되지 않으며, 획득 전에는 일반 아이템 목록에도 표시하지 않습니다.

외형 리소스는 앞뒤 전용 스프라이트 2종과 원본 애니메이션에 전용 색상을 적용하는 팔레트 스킨 2종으로 구성합니다. 원본 파일을 변형하지 않고 `SpriteImage`에서 스프라이트 시트 영역과 색상 효과를 처리합니다. 레전드플레이트는 LEGENDS 아르세우스의 실제 아이템 이미지를 사용합니다. 이미지 출처·제작자 크레딧은 [희귀 보상 이미지 문서](rare-reward-assets.md)에 기록합니다.

## 판정과 지급

배틀이 실제로 완료되면 조건에 맞는 업적을 한꺼번에 판정하고 **보상을 자동 지급**합니다. 여러 업적을 동시에 달성하면 각 보상을 합산하며, 기존 배틀 승리 보상과 업적 보상은 결과 화면에서 구분해 표시합니다. 추가 수령 버튼은 필요하지 않습니다.

저장이 성공한 새 달성은 배틀·수집 화면의 **우측 상단 알림**으로 즉시 표시합니다. 한 번에 여러 업적을 얻으면 한 카드에 묶어 대표 업적 2개와 나머지 개수, 합산 VP를 표시하고 약 5.5초 뒤 닫습니다. 연속 달성은 대기열 순서로 보여줍니다. 알림 위에 마우스를 올리거나 키보드로 집중한 동안, 브라우저 탭이 숨겨진 동안에는 시간이 멈춥니다. 게임 입력이나 포커스를 자동으로 가로채지 않으며 **업적 보기**를 누르면 설정의 업적 탭이 열립니다. 새로고침·결과 재처리는 이미 지급된 업적의 알림을 재생하지 않습니다. 이전의 수집 보상 확인 모달은 사용하지 않습니다.

- `battleEngine.js`의 `achievementFacts`를 사용하며 번역된 배틀 로그 문구로 판정하지 않습니다.
- 기절 횟수는 배틀 중 누적합니다. 회생의기도로 부활해 마지막에 전원이 살아 있어도 무기절 승리로 인정하지 않습니다. 같은 기절을 중복 계산하지 않으며, 부활 후 다시 기절하면 추가 계산합니다.
- 도구와 팀 타입은 출전 당시 정보를 보존합니다. 도구 소비·교환, 테라스탈, 폼 변화가 원래 출전 조건을 바꾸지 않습니다.
- 기믹은 실제 발동 기록을 사용합니다. 차단되어 발동하지 않은 요청은 제외하고, 종료된 다이맥스나 기믹 폼으로 시작한 포켓몬도 사용 기록에 반영합니다. 원시 폼으로 시작한 경우도 기믹 없는 승리 대상에서 제외합니다.
- AI 첫 승리는 이름 대신 카탈로그의 트레이너 ID로 구분합니다. 패배·무승부·기권은 연승을 종료합니다. 리그는 마지막 경기에서 패배해도 최종 순위가 우승이면 리그 우승 업적을 달성할 수 있습니다.
- 기존 누적 전적을 역산해 업적을 소급 지급하지 않습니다. 도입 후 구조화된 완료 정보가 기록되는 배틀부터 집계하며, 진행 중이거나 필수 판정 정보가 없는 결과에는 승리 업적을 지급하지 않습니다.

## 저장과 계정 동기화

`champions-achievements-v1`에 업적 진행도, 달성 기록, 최근 처리한 배틀 ID와 `walletBalance`를 함께 저장합니다. 이 데이터가 VP 잔액의 기준이며, **업적 달성과 증가한 잔액을 한 번의 로컬 저장으로 반영**합니다. 기존 `champions-vp-v1` 키는 호환용 잔액 사본입니다. 두 저장 사이에 새로고침이 발생해도 기준 데이터에서 업적과 잔액을 함께 복원합니다.

동일 결과 재처리는 배틀 ID와 현재 결과 정산 상태로 차단하고, 이미 달성한 업적은 다시 보상하지 않습니다. 로컬 저장 실패 시 지급 완료 상태로 진행하지 않고 재시도 안내를 표시합니다.

희귀 보상의 권리는 별도 수령 여부가 아니라 달성한 업적 ID에서 계산합니다. 먼저 업적과 증가한 VP를 함께 저장하고, 그 권리를 기준으로 박스의 지급 포켓몬과 아이템 보유 사본을 복원합니다. 업적 저장 후 박스·아이템 저장 전에 종료되어도 다음 시작 시 누락된 실물을 복원하며 VP를 다시 지급하지 않습니다. 이 복원은 반복해도 포켓몬이나 도구가 중복 증가하지 않습니다. 업적 권리가 없는 희귀 외형·도구 데이터는 로딩 과정에서 제거합니다.

업적 저장 키는 기존 `PLAYER_STORAGE_KEYS`에 포함되어 계정 데이터 내보내기·교체·클라우드 동기화에 함께 전달됩니다. 계정을 바꾸면 해당 계정의 업적 데이터로 교체됩니다. 원자적 저장의 범위는 위 로컬 데이터 한 건이며, 클라우드는 기존 계정 저장 절차를 사용합니다.

## 검증

```powershell
npm run validate:achievements
```

이 명령은 실제 배틀의 누적 기절·부활·기믹·초기 도구 판정, 업적 조건과 보상 합산·중복 방지, 7경기 전체의 무기절 우승, 실제 뽑기에서의 1,025종·이로치 도달 가능성, 마지막 업적과 전체 달성의 동시 정산, 희귀 보상의 외형·도구 효과와 AI 피해 예측, 앞뒤 8개 표시 영역과 아이템 파일의 존재·형식·시트 경계, 저장 실패와 실물·잔액 복원, 계정 데이터 교체를 검증합니다.

브라우저 통합 검증은 `npm run validate:achievements-ui`로 실행합니다. 기존 `promo` 패키지의 Playwright와 Chromium이 필요합니다 (`npm --prefix promo install`, `npx --prefix promo playwright install chromium`). 별도 런타임의 Playwright를 사용하면 `ACHIEVEMENT_PLAYWRIGHT_MODULE` 환경 변수에 모듈 경로를 지정할 수 있습니다.

통합 검증은 5185 포트의 임시 Vite 서버와 격리된 브라우저 저장소를 사용하며 실제 계정에는 접속하지 않습니다.
