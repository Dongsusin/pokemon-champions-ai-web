# 부유·혼연일체 오류 수정

## 메가한카리아스Z

메가진화가 현재 특성만 바꾸고 억제 해제용 특성에는 진화 전 `모래숨기`를 남기는 문제가 있었다. 위액 또는 화학변화가스 상태에서 진화한 뒤 교체하거나 가스가 사라지면 메가한카리아스Z가 부유 대신 이전 특성을 복구했다.

영구 배틀 폼으로 바뀔 때 복구할 특성도 새 폼의 것으로 갱신한다. 이전 가스/트레이스 복구 상태를 비우고, 위액·가스가 여전히 유효하다면 새 특성도 계속 억제한다. 메가진화 직후의 지진·대지의힘 면역, 더블에서 아군 지진 면역, 가스 퇴장 및 본인 교체 후 면역을 실제 턴 처리로 검사한다. 틀깨기가 부유를 무시하는 원래 규칙도 유지한다.

사용자가 당시 기술·상대·상태를 특정하지 않았으므로 보고된 전투가 바로 이 조건이었다고 단정하지 않는다. 일반적인 메가진화 직후 면역은 수정 전에도 통과했으며, 이번 수정은 별도로 재현한 억제/복구 오류를 해결한다.

참고: [Showdown의 영구 폼 특성 교체·억제·접지 처리](https://github.com/smogon/pokemon-showdown/blob/master/sim/pokemon.ts).

## 흑마렉스

실제 능력명 `혼연일체`가 쓰러뜨림 처리의 `흑의울음` 규칙에 연결되지 않아 특수공격 상승이 누락됐다. 현재 폼별로 흑마는 특수공격 +1, 백마는 공격 +1을 적용하고 발동 로그에는 각각 흑의울음/백의울음을 표시한다. 실제 능력은 혼연일체로 유지하여 긴장감 효과를 보존한다.

아스트랄비트로 두 마리를 쓰러뜨리면 +2, 한 마리만 쓰러뜨리면 +1이다. 직접 기술로 쓰러뜨리지 않은 독 사망에는 발동하지 않으며 능력 랭크 상한은 +6이다.

참고: [Showdown 혼연일체·흑의울음 구현](https://github.com/smogon/pokemon-showdown/blob/master/data/abilities.ts).

## 검증 및 배포 범위

- `npm run validate:mega-levitate`: 9개 통과. 변경 전 엔진을 별도 모듈 로딩으로 주입하면 복구 관련 5개가 실패한다.
- `npm run validate:calyrex-as-one`: 10개 통과. 변경 전 7개 실패를 재현했다.
- 시즌 메가 특성 32개, 1,574개 폼과 286개 트레이너 폼 설정, 기믹 선발동 20개, 풍선/접지 24개 및 기존 공통 특성·폼 회귀 통과.
- 운영용 코드는 보스전 추가 전 `origin/main`에서 만든 별도 작업 디렉터리에 이 수정 커밋만 적용해 검증한다. 보스전 커밋은 병합하지 않는다.

재현은 합법적인 포켓몬·기술·특성으로 구성한 결정론적 엔진 테스트다. 실제 유저 계정으로 운영 전투를 강제 생성하거나 승패/VP를 변경하지 않는다.
