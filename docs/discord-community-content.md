# 디스코드 커뮤니티 문구와 기본 설정

2026-09-12 기준 콘텐츠 초안. 실제 서버 게시와 설정 변경은 별도로 진행한다. 기존 문서에서 동일한 디스코드 안내는 발견되지 않았다. 게시용 payload의 원본은 [discordCommunityContent.js](../server/discordCommunityContent.js)이며, 생성한 채널 ID를 전달하면 아래 `#채널명`을 실제 채널 링크로 바꾼다. 설치 절차와 권한 적용은 별도 `discord-bot-setup.md`에서 다룬다.

게임 주소: https://pokemon-champions-area-web.co.kr

## 채널 구성과 소개

네 채널 모두 일반 서버에서 사용할 수 있는 텍스트 채널이다. `/오류`와 `/개선`의 입력 창으로 글을 작성하면 봇이 게시글별 공개 스레드를 만들고, 추가 설명과 스크린샷은 그 스레드에 남긴다. `/안내`는 게임과 채널 안내를 보여주며, `/업데이트`와 제보·제안의 상태 관리는 운영진만 사용한다.

| 채널 이름 | 채널 소개 | 일반 멤버 이용 |
| --- | --- | --- |
| 자유게시판 | 포켓몬, 팀 조합, AI 배틀 이야기와 가벼운 인사를 나누는 곳입니다. | 대화·사진·반응 |
| 오류신고 | /오류로 이상한 동작과 재현 방법을 알려주세요. 스크린샷·영상은 제보의 스레드에 남겨주세요. | 명령어 제보·스레드 첨부/답변 |
| 개선제안 | /개선으로 더 편하고 재미있는 게임을 위한 아이디어를 남겨주세요. 관련 의견은 제안의 스레드에서 나눠요. | 명령어 제안·반응·스레드 답변 |
| 업데이트내역 | 새 기능, 배틀 수정과 사용성 개선 소식을 모아 안내합니다. | 읽기·반응 |

## 채널별 고정 안내문

### 자유게시판

```text
포켓몬 챔피언스 아레나에 오신 것을 환영합니다!
좋아하는 포켓몬, 팀 조합, AI 배틀 경험을 편하게 나눠주세요.

🎮 게임 바로가기: https://pokemon-champions-area-web.co.kr
🐛 이상한 동작을 발견했다면 #오류신고
💡 새로운 아이디어는 #개선제안
📢 달라진 내용은 #업데이트내역
언제든 /안내로 게임과 채널 안내를 다시 볼 수 있어요.

서로 존중하며 이야기해 주세요. 같은 내용의 반복 게시와 무관한 광고는 삼가 주세요.
```

### 오류신고

```text
/오류로 어떤 상황에서 문제가 생겼는지 알려주세요.
이미 같은 제보가 있다면 그 글의 스레드에 경험이나 자료를 보태주세요.

제목: 어떤 문제가 있었나요?
상황: 화면/배틀 형식, 관련 포켓몬·기술·특성·도구
재현: 어떤 순서로 눌렀나요?
결과: 기대한 동작 → 실제로 일어난 동작
환경: PC/모바일, 브라우저 이름
자료(선택): 작성 후 제보 스레드에 스크린샷, 짧은 영상 또는 배틀 로그 첨부

기억나는 항목만 적어도 괜찮습니다. 한 글에는 한 가지 문제를 부탁드려요.
비밀번호·인증번호·이메일 등 개인정보는 적지 말고, 첨부 화면에 보이면 가려주세요.
```

### 개선제안

```text
어떤 점이 달라지면 더 편하고 재미있을까요? /개선으로 알려주세요.

제안: 바꾸거나 추가했으면 하는 것
이유: 어떤 상황에서 도움이 되나요?
예시(선택): 원하는 동작이나 참고 화면

이미 비슷한 제안이 있다면 반응이나 스레드 답변으로 의견을 모아주세요.
운영진은 확인한 제안에 검토 의견이나 진행 상황을 남기겠습니다.
```

## 첫 업데이트 게시문

다음 두 게시문은 커밋 날짜와 실제 변경을 기준으로 작성했다. 서버 개설 소식이나 아직 구현하지 않은 기능은 업데이트에 섞지 않는다.

```text

• 한 포켓몬의 교체를 선택하면 다음 아군의 기술 선택으로 이어지도록 수정했습니다.
• 같은 벤치 포켓몬을 두 자리에서 중복 선택할 수 없게 했으며, 먼저 고른 포켓몬에는 ‘교대 예약’을 표시합니다.
• 같은 적을 집중 공격할 때 첫 공격으로 적이 쓰러지면, 다음 단일 공격은 다른 공격 가능한 상대에게 향합니다.
• 게임 내 오류 신고 메뉴를 제거했습니다. 제보는 #오류신고를 이용해 주세요.

PC와 모바일의 교체·취소·연속 선택 및 집중 공격 흐름을 확인했습니다.
```

```text

• 풍선을 들고 있을 때 땅 기술을 피하는 효과와 풍선 소모 조건을 바로잡았습니다.
```

## 입장 환영 안내

Discord 기본 입장 메시지의 `system_channel`을 `#자유게시판`으로 설정한다. 입장할 때의 문구는 Discord 기본 메시지를 사용하고, 게임 링크와 네 채널 소개가 포함된 위 자유게시판 안내문을 고정한다. 별도의 환영 게시물·개인 DM·퇴장 알림·반복 홍보는 추가하지 않는다. 이 구성은 입장 이벤트를 받는 상시 Gateway 연결이나 자동 역할 지급이 필요하지 않다.

고정 안내 네 개와 최초 업데이트 한 개를 게시한다. 자유게시판 안내가 환영 소개를 겸하므로 동일한 소개를 다시 게시하지 않는다.

## 최소 역할과 권한

| 구분 | 기본 권한과 범위 |
| --- | --- |
| 서버 소유자 | 기존 소유자 유지. 서버·채널·역할 설정을 담당한다. |
| 운영진 | 네 채널에서 메시지 게시, 메시지 관리, 메시지 고정, 스레드 관리. 업데이트 게시를 허용한다. 서버 전체 관리자 권한은 기본으로 주지 않는다. |
| 일반 멤버 (`@everyone`) | 네 채널 보기·이전 메시지 보기·반응 추가. 앞의 세 채널에서는 메시지 보내기·파일 첨부·링크 임베드·스레드에서 메시지 보내기·앱 명령어 사용을 허용한다. 제보·제안의 공개 스레드는 봇이 만든다. |
| 커뮤니티 봇 | 지정한 네 채널 보기·이전 메시지 보기·메시지 보내기·링크 임베드. 제보·제안 채널에서는 공개 스레드 만들기·스레드에서 메시지 보내기와 상태 관리에 필요한 스레드 관리. 관리자·역할 관리·추방·차단·전체 멘션은 기본으로 주지 않는다. 최초 채널 생성·고정에 필요한 설정 권한은 설치 문서에 따라 별도로 처리한다. |

- `#업데이트내역`에서는 일반 멤버의 메시지 보내기, 스레드 만들기와 스레드 내 메시지 보내기를 차단하고 운영진의 게시만 허용한다. 읽기와 반응은 열어 둔다.
- 일반 멤버의 전체 멘션과 서버·채널·역할 관리 권한은 끈다. 별도의 가입 인증·자동 역할·레벨링은 기본 구성에 추가하지 않는다.
- 기본 알림은 멘션만, 슬로 모드는 처음에는 사용하지 않는다. 제보와 제안은 한 건의 스레드에서 후속 대화를 이어간다.
- 운영진에게 고정 권한을 줄 때는 `PIN_MESSAGES`를 확인한다. 현재 Discord 문서에서는 메시지 삭제용 `MANAGE_MESSAGES`와 별도 권한이다.

권한 명칭과 채널별 덮어쓰기는 [Discord 권한 문서](https://docs.discord.com/developers/topics/permissions), 기본 입장 메시지는 [Discord 새 멤버 메시지 안내](https://support.discord.com/hc/en-us/articles/115001156852-New-Member-Messages)를 기준으로 확인했다. 실제 서버의 기존 역할은 필요한 범위에서 유지한다.

## 설정 CLI와 공유하는 콘텐츠 계약

- `COMMUNITY_CHANNELS`: `key`(`free`/`bug`/`idea`/`update`), `name`, `topic`이 있는 배열.
- `buildCommunityGuides(channelIds)`: 채널별 고정 안내 payload를 반환한다. 자유게시판 안내에는 환영 문구·게임 링크·네 채널 링크가 포함된다.
- `INITIAL_UPDATE`: 위 두 날짜의 실제 변경을 하나의 최초 업데이트 payload로 제공한다.
- 각 payload의 `allowed_mentions`는 `{ parse: [] }`다. 안내 embed footer는 `champions-community:<key>:v1`, 최초 업데이트는 `champions-community:update:f96792c`다. CLI는 본인 봇 메시지와 marker를 함께 확인해 재실행 시 중복을 피한다.
- 게시문은 메시지 2,000자, embed description 4,096자, field value 1,024자, embed 텍스트 합계 6,000자 이내로 유지한다.
