# 2026-09-11 배틀 제보 수정

## 풍선과 땅 기술

접지 여부를 계산하는 함수는 풍선을 인식했지만 실제 피해 상성 함수가 해당 판정을 사용하지 않았다. 그 결과 지진 피해가 먼저 들어간 뒤 피격 처리에서 풍선이 소모됐다. 이제 피해 계산과 미리보기에서 동일하게 풍선·전자부유·텔레키네시스 면역을 확인한다. 틀깨기는 특성만 무시하며 풍선의 면역을 지우지 않는다.

중력·떨어뜨리기·뿌리박기·검은철구의 접지, 사우전드애로의 예외, 서투름·금제·매직룸의 도구 무효화를 구분한다. 유효한 공격이 대타에 맞아도 풍선은 터지며, 방어·땅 면역·독 등 잔여 피해로는 터지지 않는다.

## 범위 기술

이전 수정이 포함된 운영 버전에서 지진·파도타기·열풍의 다중 피해와 대상별 피격 연출은 정상임을 실제 BattleScreen으로 확인했다. 이번에는 다음 누락을 재현하고 수정했다.

- 사이코필드에서 접지된 사용자의 와이드포스: 위력뿐 아니라 대상도 상대 전체로 확장한다.
- 생명의물방울·멀리짖기: 사용자와 필드의 아군 각각에게 회복/능력 변화를 적용한다.
- 정글힐·초승달의기도: 아군별 회복과 상태 치료를 각각 한 번 처리한다.
- 아군·진영 대상 기술: 무관한 상대를 기준 대상으로 삼아 상대 특성이 아군 기술을 차단하는 경로를 바로잡는다.

일반 필드의 와이드포스, 테라 전 테라스타스톰, Z기술·다이맥스 기술로 변환된 공격은 해당 단일 대상 규칙을 유지한다. 스텔라폼 테라파고스의 테라스타스톰은 상대 전체를 공격한다.

## 기믹 발동 순서

테라·다이맥스·메가진화·선택형 원시회귀를 기술 실행에서 분리했다. 일반 교체가 끝난 뒤 변신하고, 이후 기술 행동을 진행한다. 변신 전후 스피드·특성·초상투영 등의 능력 변화로 남은 행동 순서를 다시 계산하며, 기존 동속/선제공격 도구의 난수 결과는 재사용한다.

잠듦·마비·풀죽음으로 기술을 못 쓰더라도 선택한 변신은 먼저 일어난다. 따라서 선공 상대 공격에 테라 방어 타입과 다이맥스 HP가 반영된다. AI 가상 배틀도 같은 순서를 사용한다. 교대기 선택 대기와 턴 재개 시에는 완료한 변신을 반복하지 않는다. Z기술의 힘을 방출하는 연출은 기술을 쓰는 차례에 진행한다.

## 테라타입 표시

아군 HP 패널, 파티 메뉴, 테라 버튼에서 발동 전 테라타입을 확인할 수 있다. 현재 타입과 테라타입을 구분하고, 사용 후에는 사용 중 상태를 표시한다. 상대의 미공개 테라타입은 표시하지 않는다. 테라파고스의 스텔라와 오거폰의 가면별 고정 타입을 공통 함수로 표시한다.

## 재현과 검증

```powershell
npm run validate:battle-audit
npm run validate:battle-spread-ui
npm run validate:battle-tera-info-ui
npm run validate:battle-pivots-ui
npm run validate:tera-blast-ui
npm run build
```

최종 결과: 풍선 24개, 아군 범위 19개, 기믹 순서와 타입 표시 20개, 기존 광역 22개 회귀 통과. 실제 범위 기술 UI 9개 시나리오, 테라 정보 UI 18개, 기존 테라버스트 UI 10개와 교대·부활 UI 14개도 통과했다. 통합 배틀 검사와 기술 847개·특성 313개를 포함한 14,357턴 상태 검사 및 배포용 빌드가 모두 통과했다.

신규 회귀는 합법적인 포켓몬·기술 조합을 사용한다. 기믹 순서 검사는 자동으로 보충된 기술을 fixture에서 제거해 AI가 의도한 공격 대신 방어를 선택하는 검증 오류를 방지한다. UI 검사는 실제 BattleScreen의 버튼, HP 변화, 기믹/피격 DOM 및 PC·모바일 배치를 확인한다. 통합 검사는 실행 안정성과 알려진 회귀를 확인하며 모든 기술·특성·아이템 조합의 완전 탐색은 아니다.
