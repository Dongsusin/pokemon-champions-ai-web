# 대도각참 특성 점검 (2026-09-14)

대도각참의 선택 가능한 특성은 오기·총대장·프레셔이며, 카탈로그와 저장된 선택의 정규화를 검증했다.

## 총대장

기존 구현은 공격할 때마다 현재 기절한 아군 수를 세고 최종 데미지에 배율을 곱했다. 수정 후에는 등장하거나 총대장을 새로 얻을 때 아군의 누적 기절 횟수를 저장하고 기술의 기본 위력에 보정한다.

- 누적 기절 1회마다 10%, 최대 5회·50% 증가한다. 회생의기도로 살아난 아군이 다시 쓰러진 경우도 포함한다.
- 필드에 있는 동안 새 기절이 발생해도 이미 정한 배율은 유지한다. 교대 후 재등장, 특성 재획득·억제 해제 시 갱신한다.
- 역할·동료만들기·낙서로 이미 같은 특성을 다시 지정해도 배율을 재계산하지 않는다. 실제로 특성을 새로 얻은 개체만 활성화한다.
- 물리·특수 기술에 적용되며 능력치 랭크 자체를 올리지 않는다. 실제 데미지와 AI 예상 데미지가 같은 기본 위력 보정 함수를 사용한다.
- 원본의 4096 단위 배율과 반올림을 사용한다. 예: 위력 85 도각참은 1회 기절 시 94, 5회 시 127로 계산된다.
- 발동 로그와 아군 포켓몬 상세 툴팁에 배율을 표시한다. 특성 억제 중에는 표시하지 않는다. 레이팅 상대의 비공개 정보 범위는 유지한다.
- 이전에 저장된 배틀에 활성 스냅샷이 없으면 현재 누적 기절 수로 호환 계산한다. 당시 등장 시점의 정확한 수는 이전 데이터에 없어 복원하지 못한다.

## 오기·프레셔

오기는 상대에 의해 실제 능력치 랭크가 내려갔을 때 공격을 2랭크 올리는 기존 구현을 검증했다. 위협, 여러 능력치 동시 하락, 하한에 막힌 하락, 자신·아군에 의한 하락을 구분한다.

프레셔는 상대 기술의 대상일 때 PP를 추가 소모한다. 아군 기술에 잘못 추가 소모시키던 부분, 봉인·가로챔의 `mustpressure` 대상 누락, 트리플 광역 기술에서 비인접 상대까지 세던 부분을 수정했다. 스텔스록·압정처럼 모든 상대의 프레셔를 적용하는 기술은 해당 규칙을 유지한다.

## 설명과 검증

특성 설명은 `trainingData.js`의 기존 `CURATED_ABILITY_CATALOG`에 정의하여 생성 JSON을 다시 만들어도 유지한다. 트레이닝·배틀팩토리·배틀 상세 툴팁이 같은 설명을 사용한다.

- `npm run validate:kingambit-abilities`: 총대장 전용 배틀·레이팅 직렬화, 오기·프레셔, 카탈로그·설명 검증.
- `npm run validate:kingambit-abilities-ui`: 실제 툴팁 컴포넌트의 PC·모바일 배율·설명·억제 상태 검증.

기존 총대장 검사는 등장 후 기절한 팀을 조작하던 대신 실제 교대로 특성을 활성화하도록 보완했다. 저주받은바디 검사는 유일한 기술이 봉인되면 발버둥으로 전환되는 기존 동작을 정확한 로그 문구 대신 기술 ID와 PP 유지로 검증한다.
