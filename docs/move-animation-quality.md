# 기술 연출 품질 개선 — 2026-09-10

전체 847개 기술의 연출에 준비, 발사·전개, 도착, 마무리 구간을 적용했다.
221개 기술은 53개 공통 시각 패턴에 개별 색·크기·밀도·타이밍을 지정했고,
나머지는 기술의 타입·특성 플래그·대상·연출 계열에 따라 구성을 선택한다.
847개를 모두 독립된 수작업 애니메이션으로 제작한 것은 아니다.

## 눈에 보이는 변화

| 계열 | 주요 연출 |
| --- | --- |
| 불꽃 | 화염방사의 불꽃 연쇄, 불대문자의 불꽃 大 모양, 분화의 상승 효과 |
| 물·얼음 | 하이드로펌프의 물줄기와 물보라, 냉동빔의 밝은 중심선과 얼음 조각 |
| 전기 | 10만볼트의 갈라지는 전류와 번개의 위쪽 낙하 |
| 구체 | 섀도볼의 어두운 중심, 문포스의 달, 파동탄의 회전 고리 |
| 접촉·베기 | 돌진 잔상, 엇갈린 베기, 물기, 인파이트의 불규칙한 연속 타격 |
| 흡수·회복 | 대상에서 시전자로 이동하는 흡수 입자, 회복 대상의 상승 빛과 고리 |
| 보조 | 칼춤의 회전하는 검, 방어의 둥근 보호막, 수면 입자, 씨앗의 덩굴, 거미줄 |
| 결과 | 타격·방어·빗나감·무효·실패의 서로 다른 시각 피드백 |

기존 EBDX 픽셀 소재에 추가 도형을 겹쳐 사용한다. 반복되는 원형 빛과 중복 소재,
과도한 배경 밝기는 줄였으며, 기술의 도착점과 타격 시점을 연결했다.

## 구현과 대상 처리

- `src/data/moveChoreographyData.js`: 18개 계열과 기술별 구성을 반환한다.
- `src/battleMovePainter.js`: 외부 이미지 로딩 없이 결정적인 Canvas 도형을 그린다.
- `src/MoveChoreographyCanvas.jsx`: 재생 시간, 화면 크기, 모션 감소 설정과 수명주기를 관리한다.
- `src/BattleScreen.jsx`: 실제 시전자·대상 슬롯 좌표에 Canvas와 픽셀 소재를 배치한다.

아군 회복과 상대 수면 기술을 시전자 자신에게 잘못 표시하던 분류를 수정했다.
더블배틀의 광역 기술도 개별 피격은 실제 피격 포켓몬에 맞춰 표시한다.
공격 중 포켓몬의 이동을 다시 이펙트 도착점 계산에 넣지 않도록 레이아웃 좌표를 사용한다.
좌표는 시작·크기 변경 시 갱신하며, 장면 배경이 공격 이동 값을 덮어쓰지 않는다.

Max/Z 등 변형 기술은 원래 기술의 불꽃·흡수 패턴을 무조건 이어받지 않는다.
꽃가루경단의 아군 회복 분기, 자기 대상 보호막, 필드·진영 대상도 별도로 구분한다.
피해가 없는 피격에는 피해 타격 도형과 포켓몬 흔들림을 표시하지 않는다.

## 성능과 설정

- Canvas 버퍼 너비는 최대 960px이며 작은 화면에서는 실제 너비를 따른다.
- 입자 수와 반복 횟수를 제한하고 React 상태를 매 프레임 변경하지 않는다.
- 재생 종료·컴포넌트 제거 시 RAF, 크기 관찰자, 미디어 쿼리 리스너를 정리한다.
- 일반·빠르게 모드는 전달받은 재생 시간에 맞춰 동일한 구간을 압축한다.
- 생략 모드는 기존처럼 기술 화면을 생략하면서 사운드 재생을 유지한다.
- 시스템의 모션 감소 설정에서는 이동 대신 절제된 정적 피드백을 표시한다.

## 비교 자료와 출처

[포켓로그의 공식 애니메이션 코드](https://github.com/pagefaultgames/pokerogue/blob/main/src/data/battle-anims.ts)와
[화염방사](https://github.com/pagefaultgames/pokerogue-assets/blob/beta/battle-anims/flamethrower.json),
[인파이트](https://github.com/pagefaultgames/pokerogue-assets/blob/beta/battle-anims/close-combat.json),
[흡수](https://github.com/pagefaultgames/pokerogue-assets/blob/beta/battle-anims/absorb.json)의 프레임 구성을 읽고
시전자·대상 기준 좌표, 시차, 기술별 이동 방향을 참고했다. 해당 게임 코드를 복사하거나
에셋을 추가 다운로드하지 않았으며 새 Canvas 도형은 이 프로젝트에서 작성했다.

어나더레드는 [Young의 제작·배포 원문](https://m.cafe.naver.com/ca-fe/web/cafes/31111679/articles/12376)과
제작자가 제공한 정지 홍보 이미지에서 확인한 3~5세대 픽셀 그래픽·전투 배경의 대비를 참고했다.
직접 확인하지 않은 개별 기술의 애니메이션이나 타이밍을 동일하게 재현했다고 주장하지 않는다.
기존 EBDX 소재의 출처는 [ASSET_CREDITS](../ASSET_CREDITS.md)를 따른다.
