# 상단 전체 채팅

배틀 밖의 공용 상단바 중앙에서 최신 채팅을 미리 볼 수 있다. 바를 누르면 최근 메시지를 읽고 전송하는 창이 열린다. 날짜와 시간을 확인할 수 있으며, 서버에서 인증한 공개 이름을 사용한다. Google 이름은 기존 공개 표시 규칙인 첫 글자 + `**`, 게스트는 서버에서 예약한 `guest-000000` 형식이다.

## 저장과 인증

- `POST /api/chat`은 기존 Firebase ID 토큰을 검증하고 기존 Supabase 문서 저장 어댑터를 사용한다. 클라이언트가 보낸 닉네임, 사용자 ID, 시간은 메시지 작성자나 전송 시간으로 사용하지 않는다.
- 전 사용자가 공유하는 최근 **30개**를 트랜잭션으로 보관한다. 31번째 글이 추가되면 가장 오래된 글이 삭제된다. 별도 과거 채팅 보관함은 없다.
- 채팅은 200자까지이며, 사용자별 3초 전송 간격을 서버에서 적용한다. 한글 조합 중 Enter는 전송하지 않는다.
- 요청 식별자로 네트워크 실패 후 재전송을 중복 방지한다. 사용자별 최근 16개 전송 영수증은 요청 ID와 내용 해시만 보관하며 삭제된 본문은 보관하지 않는다.
- 게스트 로그아웃의 기존 삭제 트랜잭션에서 작성한 채팅과 전송 영수증도 삭제한다. 기존 삭제 방어 장치가 오래된 인증 토큰으로 재전송하는 것을 차단한다.

## 욕설·비속어 차단

- 서버의 `chatModeration.js`가 한국어·영어의 대표적인 욕설과 비속어를 검사한다. 외부 유료 API를 사용하지 않는다.
- 공백·기호·숫자·보이지 않는 문자 삽입, 한글 자모 분리, 전각 문자, 영문 대소문자와 일반적인 숫자 치환을 비교용으로 정규화한다. 정상 메시지의 표시 내용은 변경하지 않는다.
- 감지되면 `422 / CHAT_PROFANITY`로 전송을 거절한다. 저장소를 읽거나 메시지·쿨다운·전송 영수증을 기록하기 전에 차단하므로, API 직접 호출로도 우회할 수 없다.
- 거절된 내용은 다른 사용자에게 표시되지 않는다. 작성자는 안내와 초안을 확인하고 수정하여 다시 보낼 수 있다. 주기적인 채팅 조회가 거절 안내를 지우지 않는다.
- 일반 단어와 게임 고유 명칭의 오탐을 줄이는 검증을 유지한다. 이 필터는 단어와 알려진 변형을 검사하므로 모든 신조어·문맥상의 모욕을 판별하는 것은 아니며, 새 표현은 목록과 회귀 검증에 함께 추가한다.

## 조회와 화면

- 접힌 바는 15초, 펼친 창은 4초 간격으로 확인한다. 다른 창의 채팅은 이 갱신 간격 내에 표시되며, 본인이 전송한 채팅은 응답 즉시 표시된다.
- 접힌 상태에서는 작은 최신 메시지 메타데이터만 읽는다. 펼친 상태도 버전이 같으면 전체 메시지 목록을 다시 읽지 않는다.
- 숨겨진 브라우저 탭이나 배틀 중에는 주기 조회하지 않는다. 오류가 반복되면 최대 60초까지 조회 간격을 늘린다.
- 오래된 메시지를 읽는 중에는 스크롤 위치를 유지하고 새 메시지 버튼을 제공한다. 마지막 부분을 보고 있으면 새 채팅을 자동으로 따라간다.
- 채팅창의 내용을 HTML로 삽입하지 않으며, 메시지와 입력 임시 내용은 브라우저 저장소에 저장하지 않는다.

## 로컬 검증

```sh
npm run validate:global-chat
npm run validate:global-chat-ui
npm run validate:guest-deletion
npm run validate:guest-cleanup-storage
npm run build
```

UI 검증은 실제 GameApp, 채팅 클라이언트, HTTP 핸들러와 메모리 저장소로 두 브라우저 사용자를 연결한다. 테스트 메시지는 로컬에서만 생성하며 운영 서버로 전송하지 않는다. 새 데이터베이스 마이그레이션이나 비밀 환경변수는 필요하지 않다.
