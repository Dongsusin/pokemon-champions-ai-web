# 게임 글자 크기

설정 → 게임 → **글자 크기**에서 0.5배 / 1배 / 1.5배 / 2배를 선택한다. 모바일(가로·세로 레이아웃)은 항상 1배로 고정하며 설정에서 이 항목을 표시하지 않는다. 고정된 가로 캔버스에서는 큰 배율이 조작 요소를 화면 밖으로 밀어내기 때문이다. 저장값은 지우지 않으므로 같은 계정을 PC에서 열면 이전에 고른 배율이 그대로 적용된다. 1배는 기존 화면의 크기다. 선택 즉시 배틀·메뉴·설정·툴팁에 적용하며, `champions-settings-v1`의 `game.textScale`로 기존 설정 저장/계정 동기화 흐름을 사용한다. 이전 저장 데이터에 값이 없거나 허용 값이 아니면 1배를 적용한다. 설정 기본값 복원 시에도 1배가 된다.

`main.jsx`가 첫 렌더 전에 저장값을 적용하고 `GameApp`은 설정 변경을 layout effect로 반영한다. 배율은 `html`의 `--game-text-scale`에 저장한다. 루트 글꼴 크기와 페이지 확대율, 포켓몬 이미지 크기는 변경하지 않는다.

`postcss.config.js`의 변환기는 `src` CSS의 명시적인 `font-size`에 배율을 곱한다. `clamp()`·미디어/컨테이너 쿼리·가상 요소와 명시적인 `font` 단축 선언도 포함한다. `em`·퍼센트·`inherit`는 이미 확대된 부모 글꼴을 상속하며, 숨김용 0은 유지한다. `rem`의 기준이 되는 `html`은 변환하지 않고 `body` 기본 글꼴만 1rem에 배율을 적용한다. 홍보 영상과 외부 패키지의 CSS는 제외한다.

새 글자 스타일은 인라인 `fontSize` 대신 CSS에 선언한다. 배율이 1.5/2일 때 필요한 레이아웃 보완은 `gameTextScale.css`에 두며, 큰 글자에서는 내용에 맞춘 줄바꿈과 패널 내부 스크롤을 허용한다.

포켓몬 정보 카드는 확대된 이름·타입이 고정 높이에 눌리지 않도록 별도로 공간을 확보한다. 트레이닝과 팀 편성은 목록 폭과 배율에 맞춰 열 수를 조정하고, 행 높이는 내용에 맞춘다. 이름·타입 줄바꿈을 허용하며 레벨·이로치·도구 표시가 텍스트를 가리지 않게 배치한다. 팀 편성 보완은 `scaledBoxCards.css`, 레이팅·대전방·팩토리 카드는 `scaledBattleCards.css`에 두고 기본 스타일 뒤에 불러온다. 목록이 길어지면 기존 목록/패널 안에서 스크롤하여 마지막 포켓몬까지 선택할 수 있다.

트레이닝·팀 편성 이름은 기본 1배에서도 한글 픽셀 글꼴의 실제 높이보다 줄 상자가 작았으므로 줄 높이와 행 높이를 보완했다. 0.5/1배의 열 개수와 스프라이트 크기는 유지하며, 큰 글자에서만 열 개수를 줄인다. 두 화면 높이는 고정 헤더 높이를 빼는 대신 실제 상단바 높이를 제외한 남은 공간에 맞춘다. 팀 편성 하단 선택 정보도 고정 행 대신 내용 높이를 사용한다.

`scaledTrainingEditor.css`는 1.5/2배에서 트레이닝 편집 본문을 세로 섹션으로 배치한다. 능력치 조절과 기술 세부 수치에 별도 행을 확보하고, 본문 내부 스크롤과 하단 저장 영역을 분리해 모든 설정에 접근할 수 있게 한다.

검증:

```powershell
npm run validate:game-text-scale
npm run validate:game-text-scale-ui
npm run validate:scaled-pokemon-cards-ui
npm run build
```
