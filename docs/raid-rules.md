# 보스전 규칙 (2026-09-19)

현재 보스전은 보유 포켓몬 6마리로 도전하는 솔로 3라운드 모드다. 방 목록, 방 생성, 비밀번호, 참가, 준비, 매칭 및 협동 NPC 선택 화면을 사용하지 않는다. 레이팅 배틀과 일반 대전방은 변경하지 않는다.

| 보스 | 1라운드: 6대6 더블 | 2라운드: 싱글 | 3라운드 |
| --- | --- | --- | --- |
| 뮤츠 | 로사 / 로이 | 비주기 (6대6) | 뮤츠 (6대1) |
| 칠색조 | 랜스 / 란다 | 엔테이·스이쿤·라이코 (6대3) | 칠색조 (6대1, 부활 시 본체와 부하 1마리) |
| 루기아 | 아테나 / 아폴로 | 파이어·프리저·썬더 (6대3) | 루기아 (6대1) |

로비와 동일한 저장 팀 1~5 중 출전 팀을 선택한다. 보스전에서 개별 포켓몬을 추가하지 않으며, 팀 편성 버튼으로 기존 박스 화면을 열어 편집하고 보스전으로 돌아온다. 선택한 보스는 편집 전후 유지된다. 저장된 팀의 편성 순서가 출전 순서다. 더블은 처음 2마리를 선봉으로 내보낸다. 전투 중 교대, 기절 후 대기 포켓몬 출전, 유턴 등 교대 기술을 사용할 수 있다. 승리 연출이 끝나면 중간 결과·다음 라운드·배틀 개시 버튼 없이 다음 상대의 시작 대화 장면으로 이어진다. 대화 중에는 전투 조작을 잠그며, 3초 후 자동으로 또는 대화창 클릭으로 전투를 시작한다. 패배나 기권 시 도전을 종료한다.

새 도전의 1라운드 시작과 1→2라운드 전환 시에는 모든 포켓몬의 HP를 완전히 회복하고 기절 상태를 해제한다. 2→3라운드 전환 시에만 직전 전투 종료 시의 남은 HP와 기절 상태를 그대로 이어받으며, 저장된 편성 순서에서 살아 있는 첫 포켓몬이 선봉이 된다. 다이맥스 등으로 최대 HP가 일시적으로 바뀌었다면 원래 최대 HP로 돌아가면서 남은 체력 비율을 유지한다. PP·상태이상·능력 단계·기믹 사용 횟수는 기존처럼 라운드마다 초기화한다. 다시 준비하기에서 새 도전을 시작하면 전원 회복하며 저장된 박스와 팀 데이터는 바꾸지 않는다.

## AI 편성과 전술

9개 라운드 모두 `aiDecisionLevel: hard`로 기존 하드 AI의 넓은 후보 탐색과 다음 행동 예측을 사용한다. 화면에는 `전술 하드`로 표시한다. 능력치 배율 설정은 일반 상태를 유지하므로 최종 보스의 시작 HP·능력치 1배 규칙도 유지된다.

`src/data/bossChallengeLoadouts.js`에 33개 출전 슬롯의 전용 기술 4개, 도구, 특성, 성격, 테라타입과 기믹을 정의한다. 1·2라운드는 게임 내 66점 훈련 한도와 능력치별 32점 한도 안에서 공격·내구·스피드를 배분한다. 더블 팀에는 속이다·순풍·도발·흑안개·도우미와 화상·수면 등 보조 수단을 넣고, 싱글 팀에는 교대 압박·회복·능력 강화·설치 기술을 조합한다.

- 비주기는 메가캥카, 아테나/아폴로는 메가헬가를 사용할 수 있다. 메가자리와 크로뱃에는 각각 벌레Z·비행Z를 장착하고, 다른 지정 포켓몬도 테라스탈·다이맥스를 상황에 따라 선택한다. 기존 팀당 기믹 사용 제한을 따른다.
- 최종 보스는 HP 구간에 따른 고유 기믹을 사용하며, 별도의 임의 다이맥스·테라스탈로 본체의 HP나 폼을 바꾸지 않는다. 뮤츠는 긴장감·생명의구슬, 칠색조는 프레셔·먹다남은음식, 루기아는 멀티스케일·먹다남은음식과 회복 기술을 사용한다.
- 껍질몬의 전기 테라스탈+풍선에 대비해 세 경로 모두 또도가스의 화학변화가스와 직접 상태이상 기술을 배치한다. 최종 보스 3종 모두 맹독을 가지며, 비주기의 닥트리오와 칠색조 경로의 엔테이는 모래바람도 사용할 수 있다. 실제 AI가 무효인 공격 대신 대응 기술을 선택하는지 엔진으로 검증한다.
- 칠색조가 부활시키는 엔테이·스이쿤·라이코도 2라운드의 강화된 기술·특성·도구 편성을 사용한다. 엔테이는 모래바람에 구애 고정되지 않도록 자뭉열매를 장착한다.

## 라운드별 고정 배경

각 라운드는 보스의 이야기에 맞춰 제작한 별도 장소 이미지를 사용한다. 아래 장소는 이 게임을 위한 연출 구성이다.

| 보스 | 1라운드 | 2라운드 | 3라운드 |
| --- | --- | --- | --- |
| 뮤츠 | 로켓단 지하 기지 | 비밀 유전자 연구실 | 심층 결정 동굴 |
| 칠색조 | 점거된 사찰 | 불탄 탑의 터 | 방울탑 정상 |
| 루기아 | 해저 연구 기지 | 세 전설의 해안 제단 | 소용돌이 동굴의 성소 |

배경은 `BOSS_CHALLENGES.rounds[].background`의 표시용 메타데이터로 선택한다. 필드·날씨 변화, 폼체인지, 부활 기믹으로 장소 이미지가 바뀌지 않으며 다음 라운드로 넘어갈 때 해당 장소로 전환한다. 필드·날씨의 위력 보정, 회복, 상태이상 방지, 지속시간과 파티클·오라·비 등의 연출은 실제 배틀 상태에 따라 그대로 적용한다. 일반 AI 대전은 기존 필드별 배경 전환을 유지한다.

원본 제작은 내장 `image_gen.imagegen`을 사용했다. 9개 게임용 WebP는 `public/assets/boss-backgrounds/`에 포함하며, 전체 제작 프롬프트는 [boss-background-prompts.json](boss-background-prompts.json)에 기록한다. 선택 화면에서 해당 보스의 세 배경을 미리 불러온다.

## 본 보스 기믹

본체는 레벨 50의 일반 능력치와 HP 1배로 시작한다. 명중과 회피는 구간 강화 대상이 아니다.

최종 보스 본체의 체력바는 25%·50%·75% 경계선으로 4구간을 표시하며, BOSS 표기와 남은 체력 백분율을 함께 보여준다. 구분선은 전체 최대 HP를 기준으로 고정되고 피해·회복에 따른 체력바는 연속적으로 움직인다. 75% 구간에서 최대 HP가 증가해도 현재 최대 HP 대비 비율을 사용한다. 앞선 라운드 상대, 부활한 부하 포켓몬과 플레이어의 체력바는 기존 표시를 사용한다.

- 공통 75%: HP·공격·방어·특공·특방·스피드 +1단계. HP는 최대 HP 1.5배와 현재 HP 비율 유지로 정의한다. 나머지 5개 능력은 엔진의 표준 능력 단계로 처리한다.
- 뮤츠 50%: 아머드 뮤츠. 사용자가 별도 종족값을 지정하지 않은 커스텀 외형이므로 기존 능력치·타입을 유지한다.
- 뮤츠 25%: 메가뮤츠 X/Y 중 랜덤. 저장된 공식 폼의 종족값·타입·특성·스프라이트를 적용하고 HP 강화와 기존 능력 단계를 유지한다. 과거의 2회 공격 기믹은 적용하지 않는다.
- 칠색조 50%: 2라운드 전설 3마리 중 하나를 완전 회복해 부활시키며, 그 포켓몬을 처치할 때까지 칠색조의 모든 HP 감소를 차단한다. 따라서 부하가 살아 있는 동안 25% 구간으로 넘어갈 수 없다.
- 칠색조 25%: 앞서 처치한 부하와 다른 종 한 마리를 부활시키고, 이 포켓몬을 처치할 때까지 다시 무적이 된다. 두 번째 부활은 기존 부하 슬롯을 재사용하므로 동시에 등장하는 상대는 칠색조와 부하 1마리까지다. 각 부활 포켓몬은 다음 턴부터 행동한다. 무적은 본체 체력 패널의 방패·무적 배지와 직접 공격의 대상 선택창에 표시하며, 부하 처치 즉시 해제한다.
- 루기아 50%: 다크루기아 외형으로 바뀐다. 기존 필드, 날씨, 아군 능력 단계를 초기화하지 않는다.
- 루기아 25%: 지속시간이 없는 비. 기술·특성으로 다른 날씨로 교체할 수 없다. 에어록 등 날씨 효과 억제는 기존 엔진 규칙을 따른다.

한 공격과 그 연속 타격 전체가 공유하는 피해 예산은 행동 시작 최대 HP의 25%를 내림한 값이다. 미처리 HP 구간 경계에서도 피해를 멈추므로 기믹을 건너뛰지 못한다. 원래 피해가 작으면 그 피해만 적용한다. 잔여 피해도 같은 보호 경로를 거치며, 이미 발동한 구간 기믹은 회복 후 재발동하지 않는다. 즉사·멸망의노래·길동무·강제 HP 교환으로 본체 보호를 우회하지 못한다.

## 구현 경계

- 현재 솔로 모드는 브라우저의 표준 배틀 엔진으로 실행한다. 진행 중인 도전은 화면을 떠나거나 새로고침하면 초기화된다.
- 솔로 도전에는 별도 서버 VP 정산을 연결하지 않는다. 최신 운영 코드의 계정 저장·지갑·보상 처리는 변경하지 않는다.
- 보스전은 매칭이나 서버 방 API를 호출하지 않는다. 과거 협동전 서버·계정 코드는 이 릴리스에 추가하지 않는다.
- 현재 화면은 RaidScreen → bossChallenge → BattleScreen 경로를 사용한다. raidPolicy와 raidPresentation의 공용 배틀 규칙만 재사용한다.
- 로켓단 세부 로스터는 구현 기본값이며 src/data/bossChallenge.js에서 관리한다.

## 검증

- npm run validate:boss-challenge: 9개 라운드 구성, 기본 능력치, 피해 상한, 구간별 기믹, 실제 메가폼, 무적 해제, 고정 날씨, 교대, 부활 대상/행동, 실제 AI 전투 종료.
- npm run validate:boss-challenge-ai: 9개 라운드 전용 편성과 기본 능력치 유지, 강화 AI의 실제 기믹 선택, 껍질몬의 전기 테라스탈+풍선 대응.
- npm run validate:boss-challenge-ui: 데스크톱/모바일 가로에서 팀 선택, 세 보스의 라운드 이동, 패배 종료, 부활 포켓몬 HP 패널. UI 라운드 이동 검증은 테스트 응답에만 주입한 전투 승리 상태를 사용하며 전투 승리 검증과 구분한다.
- npm run validate:boss-backgrounds: 9개 배경 로딩과 라운드별 전환, 필드·날씨 변경 중 장소 유지, 필드 연출과 실제 전투 효과, 일반 AI전의 기존 필드별 배경 전환.
- npm run build 및 표준 싱글/더블·교대 회귀 검증.

릴리스는 최신 main을 기준으로 모드 선택과 솔로 보스전만 통합한다. 고정 16:9 프레임·배틀팩토리 챌린지·계정 저장·통신 최적화는 최신 main 구현을 유지한다. 검증 후 main에 반영하고 Vercel 운영 배포의 커밋과 Ready 상태를 확인한다.

## 전체 게임 로컬 테스트


npm run boss:test 명령으로 실제 GameApp과 main.jsx의 고정 16:9 프레임, gameEntry.jsx의 전체 스타일을 사용하는 테스트 서버를 실행한다. 기본 주소는 http://127.0.0.1:5198/이며 BOSS_TEST_PORT로 포트를 변경할 수 있다. 로비에서 시작하기 → 보스전 → 보스전에 도전으로 진입한다. 전투용 포켓몬 17종(기존 게임의 진화 계열 해금 포함), 저장 팀 6마리, 100,000 VP를 최초 1회 준비한다. 이후 로컬 변경은 같은 브라우저에 저장한다. 온라인 로그인·계정·채팅·레이팅 API는 연결하지 않는다. 테스트 fixture는 운영 빌드에 포함하지 않는다.
