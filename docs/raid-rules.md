# 협동 보스전 규칙과 검증

이 기능은 사용자 요청에 맞춘 팬 게임의 협동 보스전이다. 정규 포켓몬 게임의 공식 레이드 규칙을 그대로 재현한 것으로 설명하지 않는다. 기준 명세는 2026-09-14 첨부된 `pokemon_champions_coop_boss_raid_codex_prompt.txt`이며, 아래에서 사용자 확정 요구와 초기 설계 기본값을 구분한다.

## 사용자 확정 규칙

실제 사용자 1~3명이 같은 편으로 참가하고 각 사용자는 포켓몬 한 마리만 조작한다. 세 보스 모두 전초전과 본 보스전의 두 단계로 진행한다. 플레이어 소유 포켓몬의 세대에는 제한을 추가하지 않는다.

| 보스 | 1단계 상대 | 본체 HP 50% | 본체 HP 25% |
| --- | --- | --- | --- |
| 뮤츠 | 로사·로이·비주기, 각 한 마리 | 아머드 뮤츠로 변환, 여섯 능력 +1 | 턴당 별개의 공격 두 번 |
| 칠색조 | 엔테이·라이코·스이쿤 | 앞서 쓰러진 한 마리 부활, 본체와 첫 부활 개체의 여섯 능력 +1 | 다른 한 마리 추가 부활 |
| 루기아 | 썬더·파이어·프리져 | 다크루기아, 전장 정화, 아군 랭크 초기화, 변경 불가 영구 비 | 여섯 능력 +1 |

본 보스 HP바는 75%·50%·25% 경계가 있는 네 구간이다. 한 공격으로 최대 HP의 25%를 초과해 감소하지 않는다. 아머드 뮤츠와 다크루기아는 레이드 전용 외형이며 기존 타입을 유지한다. 일반 도감에 가상의 공식 종족값이나 폼 번호를 추가하지 않는다.

## 채택할 초기 기본값

다음 항목은 사용자가 수치까지 지정한 규칙이 아니라 첨부 명세의 권장 기본값이다. 실제 구성은 `src/data/raidRules.js`의 설정을 기준으로 확인한다.

- 실제 사람 1명은 NPC 2명, 사람 2명은 NPC 1명의 지원을 받아 항상 아군 세 슬롯으로 시작한다. 사람 3명일 때 추가 NPC는 없다. 기절한 슬롯을 새 포켓몬으로 계속 충원하지 않는다.
- 로켓단 전초전은 로사/아보크, 로이/또도가스, 비주기/니드킹이다.
- 대기 포켓몬과 전투 중 교대가 없다. 유턴·볼트체인지는 피해를 처리하고 교대만 생략한다. 순수 교대 기술은 사용 불가 이유를 표시한다.
- 1단계 적 전멸 후 같은 아군 개체를 완전 회복해 2단계를 시작한다. HP·PP·기절·상태이상·일시 효과와 전장을 초기화하며 단계 전환 식별자로 한 번만 적용한다. 아군 전멸을 단계 전환으로 구제하지 않는다.
- 사용자별로 단계당 하나의 변신/특수 기믹을 허용하고 다른 사용자와 사용 횟수를 공유하지 않는다. NPC와 본 보스의 무작위 일반 변신 기믹은 사용하지 않는다.
- 본 보스가 쓰러진 행동의 반동·즉시 기절까지 처리한 뒤 아군 한 마리 이상 생존하면 승리한다. 동시 전멸은 실패다. 칠색조가 쓰러지면 남은 소환수는 퇴장한다.
- 레이드에는 포획·입장료·새 재화를 추가하지 않는다. 성공 VP는 서버가 한 번 정산하고 랭크 점수와 분리한다.
- 현재 설정은 레벨 50, 본체 기본 HP 8배, 명령 45초, 단계 최대 80턴·전체 최대 120턴, 승리 300 VP·보스별 첫 승리 추가 500 VP다. 이 수치는 초기 튜닝값이며 검증된 승률을 의미하지 않는다.

## 본 보스 HP 계산

보호는 2단계의 본체에만 적용한다. 전초전 적과 부활 소환수는 일반 피해 계산을 사용한다. `damageRootId`는 기술 한 번과 그 인과적 부가 피해를 묶으며 연속기의 각 타격에 별도 예산을 주지 않는다.

행동 시작 최대 HP를 `M`, 같은 행동에서 이미 실제 적용한 피해를 `D`라 하면 다음과 같다.

```text
남은 행동 예산 = floor(M / 4) - D
최종 피해 = max(0, min(원래 피해, 남은 행동 예산, 다음 미처리 경계까지 거리, 현재 HP))
```

실제 피해가 작은 기술을 무조건 25% 피해로 바꾸는 규칙이 아니다. 같은 턴에도 서로 다른 아군의 행동은 별도 예산을 갖는다. 첫 경계에 도달하면 해당 기술의 남은 타격은 본체 HP를 더 깎지 않으며 초과 피해를 다음 행동에 넘기지 않는다. 50% 기믹이 최대 HP를 올려도 진행 중인 공격의 예산은 다시 시작하지 않는다.

| 행동 전 HP | 원래 피해 | 실제 감소 | 결과 |
| --- | --- | --- | --- |
| 4000 / 4000 | 6000 | 1000 | 75%에서 정지 |
| 3280 / 4000 | 2000 | 280 | 75%에서 정지 |
| 3000 / 4000 | 2000 | 1000 | 50% 도달 및 기믹 |
| 4000 / 4000 | 120 | 120 | 97% |

직접·다단·고정·비례·반사·지연 피해와 독·날씨·씨뿌리기 등 모든 HP 감소는 같은 보호를 통과한다. 턴 종료 HP 감소는 하나의 residual batch로 합쳐 제한한다. 흡수·반동·피해 기록은 제한 전 예상 피해가 아닌 실제 감소량을 사용한다. 면역이나 방어로 피해가 0이면 경계 이벤트를 실행하지 않는다.

보스가 기술로 도구를 건네받은 경우도 기존 도구 효과를 유지한다. 약점 반감열매는 원래 피해를 줄인 뒤 보스의 HP 상한을 적용한다. 기합의띠처럼 기절할 피해인지 판단하는 생존 효과는 HP 상한으로 제한한 실제 피해를 기준으로 검사하므로, 75%에서 멈출 공격 때문에 기합의띠를 미리 소모하지 않는다. 마지막 HP 구간에서는 버티기가 정상적으로 1 HP를 남긴다.

75%·50%·25% 통과와 각 보스 이벤트는 독립적인 영속 플래그로 기록한다. 회복 후 재하락·재접속·트랜잭션 재시도로 같은 기믹을 반복하지 않는다. 일격필살·길동무·멸망의노래·강제 퇴장·HP 교환 등의 본체 우회 방지 정책은 보스 전용으로 적용하며 일반 배틀 규칙에 전파하지 않는다.

## 여섯 능력의 의미

공격·방어·특수공격·특수방어·스피드는 기존 능력 랭크에 +1을 더하고 정상 범위로 제한한다. 명중·회피·급소는 이 강화 대상에 포함하지 않는다.

HP는 일반 랭크와 분리된 레이드 생명력 단계(`vitalityStage`)로 표현한다. 최초 보스 최대 HP는 8의 배수로 올리며 생명력 0단계는 기본 최대 HP, 1단계는 1.5배다. 현재 HP도 같은 비율로 증가한다. 따라서 뮤츠 `2000/4000 → 3000/6000`, 루기아 `1000/4000 → 1500/6000`은 각각 50%·25%를 유지한다. 흑안개나 능력 복사는 생명력·경계·보스 권한을 초기화하거나 복사하지 않는다.

## 보스별 처리 순서

### 뮤츠

50%에서 본체의 외형과 다섯 랭크·생명력을 한 번 강화한다. 25%에서는 독립된 추가 공격을 예약하며 명중·PP·피해·대상·이벤트를 각각 처리한다. 이미 실행한 기본 행동도 한 번으로 세어 같은 턴에 최대 두 번만 행동한다. 보너스는 남은 일반 행동 뒤에 실행하고 그 전에 본체가 쓰러지면 취소한다. 순서미루기로 일반 행동을 늦춰도 보너스보다 먼저 실행하며, 보너스를 일반 행동 재정렬 대상으로 선택하지 않는다. 보너스 실행 직전에 현재 PP와 대상을 다시 평가하며, 기본 공격이 마지막 PP를 소모했다면 발버둥을 선택한다. 잔여 피해로 25%에 도달했다면 다음 턴부터 두 번이다. 수면·독·지속시간은 추가 공격 때문에 두 턴으로 진행하지 않는다.

### 칠색조

레이드 생성 시 전초전 세 개체의 부활 순서를 서버 seed로 한 번 정해 보존한다. 50%에서 첫 개체를 완전 회복해 출전시키고 본체와 그 개체만 강화한다. 25%의 두 번째 개체는 다른 종이며 별도 +1이 없다. 앞의 두 개체도 다시 강화하지 않는다. 첫 소환수가 다시 기절했어도 재부활시키지 않는다.

부활 개체는 즉시 공격 대상이 되지만 자신의 행동은 다음 턴부터다. 원본 개체 식별자와 새 전투 actor를 구분하고 슬롯 배열을 재정렬해 예약된 대상이 바뀌지 않게 한다.

칠색조 본체를 쓰러뜨리면 생존 소환수는 활성 전장과 공개 화면에서 퇴장하고 승리한다. 소환수의 HP를 0으로 만들거나 기절로 기록하지 않으며, 종료한 상태를 다시 처리해도 퇴장 이벤트를 중복 실행하지 않는다.

### 루기아

50%에서는 다크폼 변경 → 기존 전장 정화 → 아군 전체 일반 랭크 초기화 → 영구 비 설정 순서로 실행한다. 이 시점에 +1을 추가하지 않는다. 25%에서만 다섯 랭크·생명력을 강화하며 정화를 반복하지 않는다.

| 범위 | 정화 시 정책 |
| --- | --- |
| 일반·특수 날씨, 잔여 턴, 이전 날씨 복귀 상태 | 제거 후 본체 소유 영구 비 설정 |
| 지면 필드, 장막·순풍·신비의부적·흰안개 | 양측 제거 |
| 스텔스록·압정·독압정·끈적끈적네트 | 양측 제거 |
| 트릭룸·매직룸·원더룸·중력 | 제거 |
| 진영/필드의 지연 공격·지연 회복 | 제거, 소모 PP 환불 없음 |
| 아군 일반 랭크 | 기절 개체 포함 양수·음수 모두 0 |
| 아군 HP·PP·소모 도구·개체 상태이상 | 보존 |
| 개체 타입·이미 사용한 기믹·대타·충전 상태 | 보존 |
| 본체 일반 랭크·보스 이벤트·생명력 | 보존 |

정화는 한 번이며 이후 새 장막·필드·랭크 기술은 사용할 수 있다. 비 변경 잠금은 지속한다. 일반·특수 날씨 변경을 모두 차단하고 날씨 부가 효과가 있는 공격은 피해만 정상 처리한다. `999턴` 같은 임시 날씨 대신 무기한 잠금으로 표현한다. 에어록·날씨부정의 효과 무효화는 날씨 상태 변경과 구분하며, 원인이 사라지면 비 효과가 복구된다. 레이드가 끝나면 잠금은 다음 일반 전투에 남지 않는다.

## 데이터와 기존 리소스

검증 fixture는 `SPECIES_PROFILES`, `getLearnableMoves`, `getMoveById`의 실제 종·합법 기술로 구성한다. 칠색조의 canonical slug는 `ho-oh`다. 아래 외형 리소스는 기존 저장소에 존재하며 새 공식 폼 데이터를 의미하지 않는다.

- 아머드 뮤츠: `/assets/pokemon/skins/armored-mewtwo-front.gif` (기존 출처: Othienka·DarkwarePX).
- 다크루기아: `/assets/pokemon/skins/shadow-lugia-sheet.png#front` (기존 출처: Shadowgate31). `getSkinSpritePresentation`의 96×90 전면 프레임을 사용하며 전체 시트를 포켓몬 한 마리처럼 표시하지 않는다.
- 로사·로이는 기존 `로사&로이` 트레이너 리소스를 재사용할 수 있다. 로사와 로이 개별 파일이 있다고 가정하지 않는다. 비주기는 기존 `giovanni-gen3` 매핑이 있다.

기존 출처 기록은 [ASSET_CREDITS.md](../ASSET_CREDITS.md)를 따른다. 경로의 존재 검사는 로딩·사용권·모든 기기의 렌더링 검증을 대신하지 않는다.

## 검증 범위와 실행 기록

`node scripts/validateRaidMechanics.mjs`는 HP 불변식, 세 보스 기믹, 합법 기술의 세 슬롯 대상, 소유권, 상태 복원, 일반 전투 격리를 검사한다. 재현 seed와 참가 수를 고정하고 파일 내 테스트에서 명세 ID(H/M/O/L/C)를 연결한다. 소스 문자열 검색이나 프런트 HP 숫자 검사만으로 엔진 동작을 통과 처리하지 않는다.

이 문서는 로컬 단위/통합 검증과 실제 운영 검증을 구분한다. 운영 OAuth, 실물 모바일, 세 개 독립 계정의 온라인 완주, 운영 DB 장애 복구, 배포 여부는 각각 수행 결과가 있을 때만 별도 보고한다. 메모리 저장소·브라우저 에뮬레이션 통과를 운영 성공으로 표현하지 않는다.

실제 실행 명령과 기능 플래그·배포 경계는 [로컬 검증 기록](raid-qa.md)을 참고한다. 운영 서버에 이 기능을 활성화하거나 새 DB 설정을 적용하지 않았다.
