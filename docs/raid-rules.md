# 보스전 규칙 (2026-09-19)

현재 보스전은 보유 포켓몬 6마리로 도전하는 솔로 3라운드 모드다. 방 목록, 방 생성, 비밀번호, 참가, 준비, 매칭 및 협동 NPC 선택 화면을 사용하지 않는다. 레이팅 배틀과 일반 대전방은 변경하지 않는다.

| 보스 | 1라운드: 6대6 더블 | 2라운드: 싱글 | 3라운드 |
| --- | --- | --- | --- |
| 뮤츠 | 로사 / 로이 | 비주기 (6대6) | 뮤츠 (6대1) |
| 칠색조 | 랜스 / 란다 | 엔테이·스이쿤·라이코 (6대3) | 칠색조 (6대1, 부활 시 상대 슬롯 추가) |
| 루기아 | 아테나 / 아폴로 | 파이어·프리저·썬더 (6대3) | 루기아 (6대1) |

로비와 동일한 저장 팀 1~5 중 출전 팀을 선택한다. 보스전에서 개별 포켓몬을 추가하지 않으며, 팀 편성 버튼으로 기존 박스 화면을 열어 편집하고 보스전으로 돌아온다. 선택한 보스는 편집 전후 유지된다. 저장된 팀의 편성 순서가 출전 순서다. 더블은 처음 2마리를 선봉으로 내보낸다. 전투 중 교대, 기절 후 대기 포켓몬 출전, 유턴 등 교대 기술을 사용할 수 있다. 승리 연출이 끝나면 중간 결과·다음 라운드·배틀 개시 버튼 없이 다음 상대의 시작 대화 장면으로 이어진다. 대화 중에는 전투 조작을 잠그며, 3초 후 자동으로 또는 대화창 클릭으로 전투를 시작한다. 패배나 기권 시 도전을 종료한다. 라운드 사이에 같은 팀의 HP·PP·상태·기믹 사용 횟수를 완전히 회복한다.

## 본 보스 기믹

본체는 레벨 50의 일반 능력치와 HP 1배로 시작한다. 명중과 회피는 구간 강화 대상이 아니다.

- 공통 75%: HP·공격·방어·특공·특방·스피드 +1단계. HP는 최대 HP 1.5배와 현재 HP 비율 유지로 정의한다. 나머지 5개 능력은 엔진의 표준 능력 단계로 처리한다.
- 뮤츠 50%: 아머드 뮤츠. 사용자가 별도 종족값을 지정하지 않은 커스텀 외형이므로 기존 능력치·타입을 유지한다.
- 뮤츠 25%: 메가뮤츠 X/Y 중 랜덤. 저장된 공식 폼의 종족값·타입·특성·스프라이트를 적용하고 HP 강화와 기존 능력 단계를 유지한다. 과거의 2회 공격 기믹은 적용하지 않는다.
- 칠색조 50%: 2라운드 전설 3마리 중 하나를 완전 회복해 부활시킨다.
- 칠색조 25%: 앞서 부활한 종과 중복되지 않는 하나를 추가 부활시킨다. 첫 부활 개체를 포함해 살아 있는 부활 개체가 하나라도 있으면 칠색조의 모든 HP 감소를 차단한다. 부활 개체는 다음 턴부터 행동한다.
- 루기아 50%: 다크루기아 외형으로 바뀐다. 기존 필드, 날씨, 아군 능력 단계를 초기화하지 않는다.
- 루기아 25%: 지속시간이 없는 비. 기술·특성으로 다른 날씨로 교체할 수 없다. 에어록 등 날씨 효과 억제는 기존 엔진 규칙을 따른다.

한 공격과 그 연속 타격 전체가 공유하는 피해 예산은 행동 시작 최대 HP의 25%를 내림한 값이다. 미처리 HP 구간 경계에서도 피해를 멈추므로 기믹을 건너뛰지 못한다. 원래 피해가 작으면 그 피해만 적용한다. 잔여 피해도 같은 보호 경로를 거치며, 이미 발동한 구간 기믹은 회복 후 재발동하지 않는다. 즉사·멸망의노래·길동무·강제 HP 교환으로 본체 보호를 우회하지 못한다.

## 구현 경계

- 현재 솔로 모드는 브라우저의 표준 배틀 엔진으로 실행한다. 진행 중인 도전은 화면을 떠나거나 새로고침하면 초기화된다.
- 이 변경에서 새 솔로 도전에 대한 서버 VP 정산은 연결하지 않는다. 이전 협동전의 계정 지갑·보상 영수증·기록 처리 코드는 보존한다.
- 운영용 기존 보스전 API는 신규 방 생성·참가·준비·시작·방 목록 요청에 410 MATCHING_RETIRED를 반환한다. 기존 기록과 종료/정산 경로는 유지한다.
- 과거 협동전 엔진과 검증은 기존 기록 호환용이다. 현재 화면은 RaidScreen → bossChallenge → BattleScreen 경로를 사용한다.
- 로켓단 세부 로스터와 라운드 사이 전체 회복은 명시되지 않은 부분에 대한 구현 기본값이다. 로스터는 src/data/bossChallenge.js에서 관리한다.

## 검증

- npm run validate:boss-challenge: 9개 라운드 구성, 기본 능력치, 피해 상한, 구간별 기믹, 실제 메가폼, 무적 해제, 고정 날씨, 교대, 부활 대상/행동, 매칭 종료, 실제 AI 전투 종료.
- npm run validate:boss-challenge-ui: 데스크톱/모바일 가로에서 팀 선택, 세 보스의 라운드 이동, 패배 종료, 부활 포켓몬 HP 패널. UI 라운드 이동 검증은 테스트 응답에만 주입한 전투 승리 상태를 사용하며 전투 승리 검증과 구분한다.
- npm run build 및 표준 싱글/더블·교대 회귀 검증.

배포하지 않는다. codex/battle-factory 브랜치의 Vercel 자동 배포 비활성화 설정을 유지한다.

## 전체 게임 로컬 테스트


npm run boss:test 명령으로 실제 GameApp과 main.jsx의 전체 스타일을 사용하는 테스트 서버를 실행한다. 주소는 http://127.0.0.1:5198/이며 로비에서 시작하기 → 보스전으로 진입한다. 전투용 포켓몬 17종(기존 게임의 진화 계열 해금 포함), 저장 팀 6마리, 100,000 VP를 최초 1회 준비한다. 이후 로컬 변경은 같은 브라우저에 저장한다. 온라인 로그인·계정·채팅·레이팅 API는 연결하지 않는다. 배포용 코드는 테스트 실행 파일을 포함하지 않는다.
