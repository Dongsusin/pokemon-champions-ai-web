# 기술 규칙과 사용자 선택 점검 — 2026-09-11

볼트체인지 사용 후 교대 포켓몬이 무작위로 결정되는 제보를 출발점으로, 기존 전체 기술 실행 검사와 별도로 실제 효과·대상·처리 순서를 비교했다. 여러 세대의 기술과 기믹을 함께 제공하는 프로젝트이므로 현행 Pokémon Showdown 원본을 기준으로 각 기술의 동작을 확인했다.

## 턴 도중 교대 선택

- 볼트체인지·유턴·퀵턴·배턴터치·막말내뱉기·텔레포트·썰렁개그·꼬리자르기는 플레이어가 다음 포켓몬을 고른다.
- 교대 요청 시 현재 기술까지 처리하고 남은 행동 큐와 턴 번호를 보존한다. 선택 후 등장 효과를 적용하고 원래 순서대로 남은 행동을 재개한다. PP·상태 데미지·날씨 및 필드 지속 시간은 중복 처리하지 않는다.
- AI가 사용하는 교대 기술은 AI가 후보를 평가하여 선택한다. 날려버리기·드래곤테일·레드카드처럼 상대를 강제로 내보내는 효과의 무작위 교대는 구분한다.
- 방어·빗나감·타입/특성 면역·사용자 기절·교대 후보 없음·승부 종료에서는 불필요한 교대 선택을 열지 않는다.
- 탈출버튼·탈출팩·도망태세·위기회피도 플레이어가 직접 교대 대상을 선택한다. 탈출버튼/위기회피가 공격받은 상대를 돌려보내면 공격자의 유턴 교대를 중복 적용하지 않는다. 레드카드로 이미 교대된 새 포켓몬에게 원래 사용자의 유턴 효과가 잘못 이어지지 않는다.
- 입장 함정으로 선택한 포켓몬이 쓰러지면 다음 선택을 요청하고, 아직 남은 상대 행동을 보존한다.
- 회생의기도는 쓰러진 포켓몬 중 플레이어가 고른 포켓몬을 최대 HP의 절반으로 되살린다. 기술 사용자는 필드에 남는다. 더블배틀에서 필드에 남아 있는 기절한 동료도 선택할 수 있고, 다시 입장할 때 함정과 등장 효과를 적용한다. 기절 전에 예약했던 행동은 취소된 상태를 유지한다.

API는 `createBattleTurnTimeline`과 `playBattleTurnWithActions`에서 선택 대기 상태를 반환한다. `resumeBattleTurnTimeline(state, targetIndex, random)`은 선택 후 재생할 타임라인과 다음 상태를 반환한다. 기존 `forcePlayerSwitch`도 같은 재개 경로를 사용한다. 대기 데이터와 잔여 행동은 복사 가능한 상태로 저장하여 원본 배틀 상태를 변경하지 않는다.

## 개별 효과

- 배턴터치의 능력 변화/대타 및 꼬리자르기의 대타는 입장 함정·능력·도구보다 먼저 전달한다.
- 꼬리자르기는 최대 HP 절반을 올림하여 지불하고, 이미 대타가 있거나 HP/교대 조건이 충족되지 않으면 실패한다.
- 막말내뱉기는 공격·특공을 각각 1랭크 내린다. 둘 다 내릴 수 없으면 교대도 실패한다. 심술꾸러기, 미러아머, 매직미러, 하양허브 상호작용을 별도 검증한다. 생성 데이터에도 명시적인 랭크 변화 정보를 보존한다.
- 고스트타입의 저주는 HP가 절반 이하라도 사용할 수 있고, 그 비용으로 사용자가 쓰러질 수 있다.
- 힘흡수의 회복량은 대상의 공격 실수치와 랭크를 반영하며 천하장사·구애머리띠의 배율은 포함하지 않는다.
- 미래예지·파멸의소원은 대타가 있을 때 대타에 피해를 준다. 틈새포착의 대타 통과는 유지한다.
- 드래곤테일·배대뒤치기는 대타에만 적중했을 때 본체를 강제로 교대시키지 않는다.
- 매그니튜드는 행동당 한 번 7단계의 위력을 추첨하며, 같은 공격의 모든 대상에게 동일한 단계가 적용된다. 프레젠트는 위력 40/80/120의 공격 또는 대상 회복을 확률에 따라 처리한다.

## 광역 대상

지진·파도타기·열풍 등 광역 기술이 한 대상에게만 처리되던 경로를 수정했다. `allAdjacent`는 자신을 제외한 인접 아군과 상대, `allAdjacentFoes`는 인접한 상대에게 각각 적용한다. 트리플배틀에서는 슬롯 간 인접 관계를 유지한다.

명중·방어·특성 면역·대타·대상 부가 효과는 대상별로 처리한다. 여러 포켓몬을 공격할 때는 0.75배 광역 피해 보정을 적용하며, PP와 행동 소모·자가 능력 변화·생명의구슬·자가 기절은 기술 사용당 한 번 처리한다. 앞선 대상의 기절로 공격 능력이 상승하더라도 같은 광역 공격의 다른 대상 피해가 뒤늦게 커지지 않는다. 울음소리는 상대 전원, 멸망의노래는 방음 등을 확인한 필드의 각 포켓몬에게 적용한다.

광역 변화 기술의 무희 복제는 기술당 한 번 발생한다. 한 대상에게 성공하고 다른 대상에게 빗나간 기술을 전체 실패로 기록하지 않아, 다음 턴의 실패 연계 기술에 잘못된 보정을 주지 않는다. 스텔라의 최초 타입 보정은 같은 광역 공격의 모든 대상에게 유지되며 다음 사용에서는 소진된 상태를 반영한다.

npm run validate:battle-audit
npm run validate:battle-pivots-ui
