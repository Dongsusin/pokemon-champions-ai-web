# 트레이닝의 빈 기술

기술 변경 창 하단의 **빈 기술로 설정**으로 선택한 기술을 지울 수 있다. 기술은 최소 1개가 필요하므로 마지막 기술과 이미 빈 슬롯에는 비우기 버튼이 비활성화된다. 미리보기 폼은 편집할 수 없다. 빈 슬롯을 선택하면 기존 기술 목록에서 다시 배울 수 있다.

저장 데이터의 `moves`는 실제 기술 이름만 담는 길이 1–4의 배열이다. 기술을 지우면 남은 기술이 앞 슬롯부터 정렬되며, 트레이닝 화면에서만 뒤쪽 빈 슬롯을 더해 항상 4칸을 표시한다. 빈 슬롯은 배틀 기술이나 PP로 생성하지 않는다. 기존 `moveIds`가 있는 데이터는 수정된 기술과 함께 갱신한다.

명시적으로 설정한 1–3개 기술에는 기본 기술을 덧붙이지 않는다. 기술 배열 자체가 없는 기존 데이터는 종전의 기본 기술 구성을 적용하고, 빈 배열이나 전부 잘못된 기술인 데이터는 배울 수 있는 기본 기술 하나로 복구한다. 트레이닝 저장 경계에서도 배울 수 있는 기술이 최소 하나 있는지 확인한다.

기술 추가·삭제·교체는 기존 기술 변경 단가인 100 VP를 사용한다. 삭제로 다른 기술의 슬롯 번호가 당겨지는 것은 별도 변경으로 과금하지 않는다. 예를 들어 4개 중 첫 기술 하나만 삭제하면 100 VP, 3개를 삭제하면 300 VP이다.

검증:

```powershell
npm run validate:training-move-slots
npm run validate:training-move-slots-ui
npm run validate:training-moves
npm run validate:pokemon-forms
npm run build
```
