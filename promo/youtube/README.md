## 사용할 파일

- `title-ko.txt`: 추천 제목만 들어 있는 파일.
- `description-ko.txt`: 설명란에 그대로 붙여 넣을 본문. 실제 영상의 챕터 8개와 음악 크레딧 포함.
- `champions-arena-youtube-thumbnail.jpg`: 업로드용 썸네일. 휴대폰에서도 사용할 수 있도록 2MB 미만으로 인코딩했습니다.
- `champions-arena-youtube-thumbnail.png`: 생성 원본. JPG와 같은 디자인·해상도이며 PNG 원본을 보존했습니다.
- `upload-copy-ko.md`: 추천 제목·대안 2개·설명·제작 근거.
- `thumbnail-prompt.txt`: 내장 `image_gen`으로 제작할 때 사용한 전체 프롬프트.
- `validation.json`: 제목 길이·챕터·파일 크기·해시 검증 결과.

썸네일은 1672×940픽셀의 가로 이미지입니다. 큰 한글 제목, 눈에 띄는 `비공식 팬메이드` 표시, 독자적인 경기장과 에너지 충돌 그래픽으로 구성했습니다. 게임의 스크린샷을 나타내는 이미지는 아니며, 생성형 홍보 그래픽입니다. 한글 문구와 수치, 캐릭터·공식 로고가 추가되지 않은 것을 시각적으로 확인했습니다. JPG는 동일 이미지를 다른 파일 형식으로 인코딩한 것입니다.

## 저작권 관련 확인 범위

- YouTube는 출처, 비영리, 침해 의사가 없다는 표시만으로 콘텐츠 사용 권리가 생기지 않는다고 안내합니다. [저작권에 대한 일반적인 오해](https://support.google.com/youtube/answer/2797449?hl=ko)
- 닌텐도 가이드의 범위는 정해진 조건의 게임 영상·스크린샷 공유이며, 다른 지식재산 이용까지 허락하는 문서는 아닙니다. 팬게임 제작·배포·홍보에 그대로 적용하여 허락을 받았다고 판단할 수 없습니다. 공식 제휴·후원 오인도 피해야 합니다. [Nintendo 가이드, Q6 및 본문](https://www.nintendo.co.jp/networkservice_guideline/en/index.html)
- 현재 음악은 포켓몬 공식 OST가 아니라 Spring Spring의 **Face The Champion!**입니다. 원본 페이지의 선택 가능한 **CC BY 3.0**과 제작자 표시를 확인했습니다. 설명에는 `Julie Damsgaard/Spring Spring/Spring Enterprises`, 제작자 주소, 제목·원본·라이선스 링크·편집 내역을 넣었습니다. [원본](https://opengameart.org/content/face-the-champion), [CC BY 3.0 조건](https://creativecommons.org/licenses/by/3.0/)
- 위 음악 라이선스는 포켓몬 캐릭터·스프라이트·울음소리의 권리까지 허락하지 않습니다. 현재 영상에는 해당 자료가 포함되어 있고, 프로젝트의 출처 문서에서 별도 권리자의 홍보 이용 허락은 확인하지 못했습니다. 게임 장면을 직접 촬영했다는 사실만으로 그 안의 모든 자료에 대한 권리가 확보되는 것은 아닙니다. 공개 전에 이 범위를 확인하거나 필요한 자료를 허락받은 자산으로 교체해야 합니다. [YouTube의 직접 녹화 관련 안내](https://support.google.com/youtube/answer/2797449?hl=ko)

비영리 운영·무료·수익화 중단은 확인되지 않은 사항이므로 업로드 문구에 넣지 않았습니다. 권리자 표기는 제휴나 승인을 의미하지 않습니다.
