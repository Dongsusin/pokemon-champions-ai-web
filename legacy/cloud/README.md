# 이전 웹 배포 참고 자료

이 디렉터리는 이전 Vercel API 진입점과 Firebase 배포 설정을 보관한다.
현재 게임은 이 파일들을 실행하거나 배포하지 않는다. 클라우드 의존성도
루트 package.json에서 제거했다. 기존 server/의 서비스 로직은 개인 운영
서버를 준비할 때 참고할 수 있으나 기존 Google/Firebase 인증 코드를 그대로
새 게스트 서비스에 사용해서는 안 된다.

실행·저장·런처 연결 규격은 ../../docs/LOCAL_LAUNCHER.md를 참고한다.
과거 클라우드 검증 명령은 새 로컬 게임의 검증 명령이 아니다.
